# Round 11 — 大作感打磨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline — tasks share
> screen_battle.gd/main.gd heavily; subagent-per-task would thrash). Steps use `- [ ]` checkboxes.

**Goal:** Audio (BGM+SFX+mixing), key-moment VFX (hit-stop / death dissolve / boss intro), directional
screen transitions, UI feel, haptics — visual/audio/motion only, zero gameplay-value changes.

**Architecture:** Two new autoloads (`Music` for BGM crossfade/duck, `Fx` for hit-stop/particles/haptics),
runtime audio buses (Music/SFX under Master), a transition overlay owned by `main.gd`, and per-screen
moment work. All new effects gated by `fast_anim` (existing) + `reduce_fx` (new). Assets are CC0-only:
Kenney packs for SFX where downloadable, `tools/music_build.py` (numpy+soundfile→OGG) for BGM and any
SFX gaps — procedural output is unambiguously ours.

**Tech Stack:** Godot 4.7.1 GDScript, Python 3.14 + numpy + soundfile (OGG vorbis write verified),
Playwright (headed Chromium) for video verification.

## Global Constraints

- 只准改視覺/音訊/動效;嚴禁改 gameplay 數值/規則(data/*.json 數值、battle_core 規則、sim 一律唔掂;
  唯一例外:settings dict 加 presentation keys)。
- 16 suites 全綠(`bash tools/test_all.sh`),contrast/layout/legibility/parity 一條唔准鬆。
- 資產授權:CC0 或 OFL only(CC-BY 可但要記 attribution;NC/SA 一律唔准)。`CREDITS.md` 逐項記
  來源/作者/授權/連結。
- 音訊總增量 ≤ ~10MB;最終首載(pck+wasm gzip 後)>18MB 就要減 bitrate。
- Web autoplay:首次互動先起音訊(Godot web 會自動 resume AudioContext,驗真機)。
- 轉場 0.2–0.3s;「快速動畫」設定同樣生效;worst frame 目標 <33ms(hit-stop 刻意凍結唔計)。
- 老規矩:結尾 commit + `bash tools/web_build.sh` + push + 驗 live URL(curl pck 大細 + 開頁驗)。
- 唔准停低問;判斷記入 DECISIONS.md。

### Task 3: BGM — tools/music_build.py + Music autoload

**Files:** Create `tools/music_build.py`, `assets/audio/bgm/{title,ch1,ch2,ch3,boss,win,lose}.ogg`,
`scripts/autoloads/music.gd` (autoload `Music`, registered in project.godot after Sfx).

**Interfaces produced:**
- `Music.play(track: String, fade := 0.8)` — crossfades between two AudioStreamPlayers on Music bus;
  no-op if already playing that track. `Music.stop(fade)` fades out. `Music.duck(db := -10.0, dur := 1.2)`
  — dips music (for win stinger), auto-recovers. Stingers are Sfx (`win`/`lose`) over ducked BGM.
- Track policy wired where screens change: menu/charselect/codex/meta → `title`; map/battle/shop/rest/
  treasure/event/reward by chapter → `ch1/ch2/ch3`; boss battle → `boss` (switched by boss-intro seq);
  victory → duck + win stinger; gameover → lose stinger.
- Loop points: OGG loop=true via import options (or AudioStreamOggVorbis.loop at load); compose to
  bar-exact lengths so loop seams are clean.
- Composition per spec: title=calm forest; ch1=翠綠明亮, ch2=暮橙緊張, ch3=暗紫壓迫, boss=drive.
  Karplus-Strong plucks + detuned pads + wind bed; each ≤ ~90s loop, target ≤ 1.5MB each, total ≤ 9MB.

- [ ] Write music_build.py, generate, listen-check spectrograms/rms (no clipping), import into Godot.

### Task 4: Fx autoload — hit-stop, particles, haptics, gates

**Files:** Create `scripts/autoloads/fx.gd` (autoload `Fx`, last). Modify `project.godot`.

**Interfaces produced:**
- `Fx.hit_stop(msec := 50)` — `Engine.time_scale = 0.05` then restore after real-time msec
  (timer with `ignore_time_scale`); no-op when `reduce_fx` or during another stop.
- `Fx.burst(parent: Control, pos: Vector2, color: Color, n := 12, speed := 220.0)` — one-shot
  CPUParticles2D, self-freeing; no-op when reduce_fx.
- `Fx.dissolve(target: Control, tint := Color(1,0.3,0.9))` — corruption death: clone target as
  TextureRect snapshot? NO — operates in-place: fades target, spawns upward magenta drift particles
  + one rim flash rect; returns a Signal-ish `Tween` caller can await. reduce_fx → quick fade only.
- `Fx.dust(parent, pos)` — small landing puff.
- `Fx.vibrate(ms := 20)` — `Input.vibrate_handheld(ms)` + web `JavaScriptBridge.eval("navigator.vibrate&&navigator.vibrate(%d)")`,
  gated by `settings.haptics`, wrapped in feature check, silent no-support fallback.
- `Fx.flash_screen(color, alpha, dur)` — full-rect flash for big casts / boss warn.
- `Fx.reduced() -> bool`, `Fx.fast() -> bool` — the two gates, read by screens.

- [ ] Implement + register autoload. Headless-safe (no crash without display). Suites green. Commit.
